# Exploratory Data Analysis on Customer Dataset

## Overview

This project was completed as part of the Advanced Data Science coursework at SRM University–AP.

The objective was to apply exploratory data analysis techniques to a customer dataset to understand its characteristics, identify patterns, and derive meaningful insights through data analysis and visualization.

## Objectives

- Understand the structure and characteristics of the customer dataset.
- Perform exploratory data analysis to investigate patterns and relationships.
- Apply data analysis and visualization techniques to interpret the data.
- Identify meaningful observations from the analysis.
